# Прогноз режима электросети

Проект рассчитывает напряжения и фазовые углы в 35 узлах, токи и загрузку в 80 ветвях, а также вероятность сходимости режима.

## Запуск

1. Положить `train_nodes_34_100000.csv` и `train_lines_34_100000.csv` из архива в папку `dataset`. Можно также указать пути к CSV через `--nodes` и `--lines`.
2. Выполнить `python start.py train --epochs 160`. Нужен Python 3.10 или новее. Если интерпретатор доступен как `python3`, использовать эту команду вместо `python`. Скрипт подготовит `.venv` и установит зависимости.
3. Модель и метрики появятся в `results/model.joblib` и `results/metrics.json`. В репозитории уже есть веса, обученные на данных хакатона.

Прогноз для новых режимов

```sh
python start.py predict --nodes test_nodes_34.csv --lines test_lines_34.csv
```

Для автопроверки после установки зависимостей из `requirements.txt` используется вызов из шаблона организаторов.

```sh
python baseline_solution.py --nodes test_nodes.csv --lines test_lines.csv --out-dir predictions
```

Автопроверка получает `pred_nodes.csv` и `pred_lines.csv` с тем же порядком строк, что у входных файлов. Столбцы узлов: `ID_опыта`, `Номер`, `V`, `Delta`, `Regime_valid`. Столбцы ветвей: `ID_опыта`, `Номер`, `Imax, A`, `Izarg, %`. Обычный запуск прогноза дополнительно записывает вероятность сходимости в `results/pred_regimes.csv`.

## Модель и оценка

Один пример соответствует одному полному режиму. Признаки узлов и ветвей соединяются по ID опыта и упорядочиваются по номерам элементов. ID, эталонные напряжения, токи и флаг сходимости исключены из признаков. Столбец `I_доп` тоже исключён: в учебном архиве он заполнен только для сошедшихся режимов и по его наличию можно заранее узнать ответ.

Используются две полносвязные модели. Классификатор обучается на всех режимах, регрессор возвращает четыре группы величин и обучается на сошедшихся режимах. Постоянные признаки отбрасываются, остальные стандартизируются по обучающим данным. Порог классификации выбирается по F1-macro на валидации.

Из 100 000 режимов 60 000 выделены для обучения, 20 000 для подбора порога и 20 000 для локальной проверки. F1-macro считается по всем отложенным режимам. MAE, RMSE и R² для напряжений и токов считаются по эталонам сошедшихся режимов. В метриках приведены два сравнения на той же выборке: среднее по каждому узлу или ветви и вариант организаторов без обученных весов (номинальное напряжение, нулевые углы и токи, сходимость 1).

На локальной отложенной выборке F1-macro составил 1,000. В этом архиве диапазоны суммарной активной генерации двух классов не пересекаются. Качество в других условиях генерации пока не измерено. Ошибки регрессии рассчитаны по 10 017 сошедшимся режимам.

| Величина | MAE модели | MAE по среднему |
| --- | ---: | ---: |
| Напряжение, кВ | 0,078 | 5,003 |
| Фазовый угол, ° | 0,024 | 1,984 |
| Максимальный ток, А | 0,848 | 42,800 |
| Загрузка ветви, п. п. | 0,132 | 5,891 |

Полная таблица с RMSE и R² находится в [results/metrics.json](results/metrics.json). Официальная оценка на закрытой выборке проводится организаторами.

## Самопроверка

```sh
python start.py check
```

Самопроверка использует искусственные данные и проверяет оба способа запуска, столбцы CSV и сохранение порядка строк. Её результаты сохраняются в `results/check`.
