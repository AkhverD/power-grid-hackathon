# Прогноз режима электросети

Проект рассчитывает напряжения и фазовые углы в 35 узлах, токи и загрузку в 80 ветвях, а также вероятность сходимости режима.

## Запуск

1. Положить рядом со `start.py` файлы `train_nodes_34.csv` и `train_lines_34.csv`.
2. Открыть терминал в папке проекта и выполнить `python start.py`. Нужен Python 3.10 или новее. Если интерпретатор доступен только как `python3`, выполнить `python3 start.py`. Скрипт при необходимости создаст `.venv` и установит зависимости.
3. Забрать `results/metrics.json` с оценкой и `results/model.joblib` с обученной моделью.

Прогноз для новых режимов

```sh
python start.py predict --nodes test_nodes_34.csv --lines test_lines_34.csv
```

В тестовых таблицах нужны идентификаторы режимов, номера элементов и входные параметры. Столбцы с эталонными ответами можно убрать. Прогноз записывается в `results/pred_nodes.csv`, `results/pred_lines.csv` и `results/pred_regimes.csv`. Ветки различаются по номеру, поэтому линии между одними и теми же узлами сохраняются. Номера должны соответствовать схеме обучения. Напряжения и токи записываются для каждого режима, признак сходимости позволяет отфильтровать результаты.

## Модель и оценка

Один пример соответствует одному полному режиму. Признаки узлов и ветвей соединяются по ID опыта и упорядочиваются по номерам элементов. ID, эталонные напряжения, токи и флаг сходимости исключены из признаков. Из токовых величин на вход подаётся только заданный допустимый ток ветви `Iдоп`.

Используются две полносвязные модели. Классификатор обучается на всех режимах, регрессор возвращает четыре группы величин и обучается на сошедшихся режимах. Постоянные признаки отбрасываются, остальные стандартизируются по обучающим данным. Порог классификации выбирается по F1-macro на валидации.

Разбиение по режимам составляет 60% на обучение, 20% на валидацию и 20% на отложенную проверку. Для напряжений и токов считаются MAE, RMSE и R² по всем значениям каждой величины в сошедшихся режимах. Для сравнения в отчёте есть ошибка при прогнозе среднего значения по каждому узлу или ветви. F1-macro считается на всех режимах отложенной выборки.

## Самопроверка

```sh
python start.py check
```

Самопроверка обучает модели на искусственных данных и проверяет метрики и формат прогноза. Её модель, метрики и прогнозы сохраняются в `results/check` внутри проекта. Для итоговой оценки качества нужны исходные данные хакатона.
